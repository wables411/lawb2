## Chess

**Single player**
- Easy mode: random AI.
- Vs Clawb: Stockfish-powered (hard), Clawb comments in game chat. Stockfish API: chess.lawb.xyz.

**PVP on-chain (LAWBCHESS3000)**
- Create a game with a token wager → share invite code → opponent joins with same wager → play → winner takes all (minus small house fee) on-chain.
- **Chains:** Base (primary), Sanko, Arbitrum.
- **Wager tokens:** ETH, USDC, LAWB, GG, DMT, GOLD, MOSS, WABLES411, etc. ERC-20 supported per chain.
- **How to play:** Connect wallet → choose chain → set wager and token → create game → share code → opponent joins → play.

## Common Issues

- **Wallet not connecting:** Use a browser wallet (MetaMask, Coinbase Wallet, etc.) or WalletConnect. Refresh if needed.
- **Wrong chain:** App will prompt to switch. Chess PVP on Base = be on Base network.
- **Transaction failed:** Check gas (ETH on the right chain) and token balance for wager.
- **Chess stuck:** Refresh. Vs Clawb has a move timeout (e.g. 60 minutes).
- **Can't see NFTs:** Connect wallet; gallery reads from connected wallet.
