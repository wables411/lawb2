# Lawb.xyz Knowledge Base — For Clawb's Context

## What is lawb.xyz?
lawb.xyz is the Lawb OS — a Windows 98-style desktop web app for the Lawbsters NFT ecosystem. It has chess (single player + on-chain PVP wagers), NFT minting, galleries, a meme generator, and public chat. Everything styled as draggable Win98 windows.

## Routes
- `/` — Lawb OS desktop. Icons, draggable windows, taskbar, Clawb walking around.
- `/chess` — Full chess experience. Single player (easy mode, vs Clawb hard mode), PVP on-chain wagers, chat, lobby.
- `chess.lawb.xyz` — Chess subdomain, same experience as /chess.

## Chess
- **Single Player**: Easy mode (random AI) or vs Clawb (Stockfish-powered, hard mode).
- **PVP On-Chain**: Create a game with a token wager. Opponent joins by matching the wager. Winner takes all minus a small house fee. Uses the LAWBCHESS3000 smart contract.
- **Supported chains for PVP**: Base (primary), Sanko, Arbitrum.
- **Supported wager tokens**: ETH, USDC, LAWB, GG, DMT, GOLD, MOSS, and more. Any ERC-20 is accepted.
- **How to play PVP**: Connect wallet → choose chain → set wager amount and token → share invite code → opponent joins → play → winner auto-paid on-chain.

## Common Issues
- **Wallet not connecting**: Make sure you have a browser wallet (MetaMask, Coinbase Wallet, etc.) or use WalletConnect. Try refreshing the page.
- **Wrong chain**: The app will prompt you to switch. For chess PVP on Base, you need to be on Base network.
- **Transaction failed**: Check you have enough gas (ETH on the right chain) and enough tokens for the wager.
- **Chess moves not working**: If the board seems stuck, try refreshing. The AI has a 60-minute move timeout.
- **Can't see NFTs**: Make sure wallet is connected. Gallery pulls from your connected wallet.
